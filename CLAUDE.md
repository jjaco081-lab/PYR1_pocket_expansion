# PYR1_pocket_expansion

Computational viability assessment of expanding the *Arabidopsis* PYR1
ligand-binding pocket for biosensor engineering. Two arms: pocket expansion /
scaffold design, and library design for small-ligand sensors.

**The durable record is `README.md` (§0–§127) and `METHODS_REVIEW.md`.** This
file is the recall index for it: one line per stored finding, loaded only when
working in this repo. Cross-project working rules live in the global
`MEMORY.md`; everything below is specific to PYR1 and does not belong there.
