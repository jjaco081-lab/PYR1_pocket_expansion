3. PRE-REGISTRATION for the sealed sets (sd08 TNT, sd09 PFAS)
================================================================================
   Written before either sheet is read, and falsifiable in the obvious way.

   The rule, stated so it can fail:
     For a target class, compute over round-1 clones whose ligand has
     Tanimoto >= 0.4 to the class:  P(mutated) and P(top residue | mutated).
     PREDICT that any position with P(top | mutated) >= 0.85 on n >= 8
     class clones will carry that residue in >= 80 % of that class's
     round-2 sensors, and may therefore be FORCED.

   On the coumarin dev set this rule fires exactly once (V163W: 91 % on
   n = 11) and is right (95 % of round-2 sensors). A rule that fires once
   on one class is not yet a method -- the sealed sets are what decide it.

   It fails if: it fires on a position whose round-2 frequency is < 80 %,
   or fires nowhere on either sealed class while a forceable position
   exists in their round-2 data.
